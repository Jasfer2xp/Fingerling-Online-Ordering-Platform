# User Guide

## 🎯 Getting Started

Welcome to the Fingerling Trading Platform! This guide will help you navigate and use all the features available to your user role.

## 👤 User Roles

### 🔑 Administrator
Complete system control and oversight

### 🏪 Supplier  
Manage inventory and process orders

### 🛒 Customer
Browse products and place orders

## 🚪 Logging In

1. Navigate to the platform URL
2. Click "Login" or go to `/auth/login.php`
3. Enter your email and password
4. Click "Sign In"

### First Time Users
1. Click "Register" or go to `/auth/register.php`
2. Fill in your information
3. Select your user type (Supplier/Customer)
4. Submit registration
5. Wait for approval (Suppliers only)

## 👑 Administrator Guide

### Dashboard Overview
- **User Statistics**: Total users by type
- **Order Analytics**: Recent order trends
- **Revenue Tracking**: Financial overview
- **System Health**: Platform status

### User Management
1. **Navigate**: Admin Panel → Users
2. **View Users**: See all registered users
3. **Approve Suppliers**: Review and approve new suppliers
4. **Manage Status**: Activate/deactivate accounts
5. **View Details**: Access user profiles

### Product Oversight
1. **Navigate**: Admin Panel → Products
2. **Monitor Inventory**: View all products
3. **Manage Categories**: Add/edit species categories
4. **Quality Control**: Review product listings

### Order Management
1. **Navigate**: Admin Panel → Orders
2. **Monitor Orders**: Track all transactions
3. **Resolve Issues**: Handle disputes
4. **Generate Reports**: Export order data

### Financial Management
1. **Navigate**: Admin Panel → Payments
2. **Track Payments**: Monitor transactions
3. **Process Refunds**: Handle refund requests
4. **Financial Reports**: Generate revenue reports

## 🏪 Supplier Guide

### Getting Started
1. **Register**: Create supplier account
2. **Wait for Approval**: Admin will review your application
3. **Complete Profile**: Add business information
4. **Add Products**: Start listing your fingerlings

### Dashboard Overview
- **Sales Summary**: Revenue and order statistics
- **Recent Orders**: Latest customer orders
- **Inventory Status**: Stock levels and alerts
- **Performance Metrics**: Ratings and reviews

### Managing Inventory
1. **Navigate**: Supplier Panel → Inventory
2. **Add Products**: 
   - Click "Add New Product"
   - Select fish species
   - Set price and stock quantity
   - Add product images
   - Specify minimum order quantities
3. **Edit Products**: Update existing listings
4. **Stock Management**: Monitor and update stock levels

### Processing Orders
1. **Navigate**: Supplier Panel → Orders
2. **View New Orders**: Check pending orders
3. **Confirm Orders**: Accept or decline orders
4. **Update Status**: Mark orders as preparing, ready, shipped
5. **Delivery Coordination**: Arrange delivery with customers

### Business Profile
1. **Navigate**: Supplier Panel → Profile
2. **Business Information**: Update company details
3. **Contact Information**: Manage contact details
4. **Location**: Set business location for map display
5. **Description**: Add business description

### Analytics
1. **Navigate**: Supplier Panel → Analytics
2. **Sales Reports**: View sales performance
3. **Customer Analytics**: Understand customer behavior
4. **Product Performance**: Track best-selling items

## 🛒 Customer Guide

### Getting Started
1. **Register**: Create customer account
2. **Complete Profile**: Add delivery address
3. **Browse Products**: Explore available fingerlings
4. **Start Shopping**: Add items to cart

### Dashboard Overview
- **Order History**: Recent purchases
- **Favorites**: Saved products
- **Recommendations**: Suggested products
- **Account Summary**: Order statistics

### Browsing Products
1. **Navigate**: Customer Panel → Browse Products
2. **Search**: Use search bar for specific species
3. **Filter**: Filter by price, location, category
4. **Sort**: Sort by price, rating, distance
5. **View Details**: Click products for more information

### Shopping Cart
1. **Add Items**: Click "Add to Cart" on products
2. **View Cart**: Navigate to Shopping Cart
3. **Update Quantities**: Adjust item quantities
4. **Remove Items**: Delete unwanted items
5. **Proceed to Checkout**: When ready to order

### Placing Orders
1. **Review Cart**: Verify items and quantities
2. **Delivery Address**: Confirm delivery location
3. **Payment Method**: Select payment option
4. **Place Order**: Submit your order
5. **Order Confirmation**: Receive order number

### Order Tracking
1. **Navigate**: Customer Panel → My Orders
2. **View Status**: Track order progress
3. **Order Details**: View complete order information
4. **Contact Supplier**: Communicate about orders
5. **Confirm Delivery**: Mark orders as received

### Finding Suppliers
1. **Navigate**: Customer Panel → Suppliers
2. **View Map**: See supplier locations
3. **Supplier Profiles**: View business information
4. **Read Reviews**: Check supplier ratings
5. **Contact Suppliers**: Get in touch directly

### Managing Profile
1. **Navigate**: Customer Panel → Profile
2. **Personal Information**: Update contact details
3. **Delivery Addresses**: Manage delivery locations
4. **Order History**: View past purchases
5. **Account Settings**: Change password, preferences
