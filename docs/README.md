# Fingerling Trading Platform

A comprehensive web-based platform for trading fingerlings (young fish) between suppliers and customers, with complete administrative oversight.

## 🚀 Features

### Admin Panel
- **User Management**: Approve/reject suppliers, manage customers
- **Product Management**: Oversee all products and inventory
- **Order Management**: Monitor all transactions
- **Financial Management**: Track payments and refunds
- **Analytics**: Comprehensive reporting and insights
- **System Settings**: Platform configuration

### Supplier Panel
- **Inventory Management**: Add, edit, and manage fish species
- **Order Processing**: Handle customer orders
- **Business Profile**: Manage business information
- **Analytics**: Track sales and performance

### Customer Panel
- **Product Browsing**: Search and filter available fingerlings
- **Shopping Cart**: Add items and manage orders
- **Order Tracking**: Monitor order status
- **Supplier Discovery**: Find and evaluate suppliers
- **Profile Management**: Manage personal information

## 🛠 Technology Stack

- **Backend**: PHP 8.0+
- **Database**: MySQL 8.0+
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Framework**: Bootstrap 5.3
- **Icons**: Font Awesome 6.0
- **Maps**: Leaflet.js with OpenStreetMap

## 📋 Requirements

- PHP 8.0 or higher
- MySQL 8.0 or higher
- Apache/Nginx web server
- Modern web browser (Chrome, Firefox, Safari, Edge)

## 🚀 Installation

1. **Clone/Download** the project to your web server directory
2. **Import Database** using the provided SQL file
3. **Configure** database settings in `config/config.php`
4. **Set Permissions** for upload directories
5. **Access** the platform via your web browser

## 🔧 Configuration

Edit `config/config.php` to set:
- Database connection details
- Application settings
- File upload paths
- Email configuration (if needed)
